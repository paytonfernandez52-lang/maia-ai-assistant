# MAIA — My Adaptive Intelligence Assistant

A voice-enabled personal AI assistant accessible from any device.

## Features
- Natural language conversation powered by Claude AI
- Text-to-speech responses via ElevenLabs (Maria voice) with speed controls
- Voice input transcription via OpenAI Whisper
- Real-time data — weather, exchange rates, trivia, sunrise/sunset, jokes, and more
- Image generation via Pollinations.ai
- Persistent cross-session memory backed by Supabase
- PIN-protected access

## Stack
HTML · JavaScript · Claude API · ElevenLabs · OpenAI Whisper · Supabase · Netlify Functions
